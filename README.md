# Online Quiz System

## 1. Project Description

The **Online Quiz System** is a software development and quality audit project undertaken as part of **BBAT104 – Fundamentals of Total Quality Management (TQM), Academic Session 2026–27**. The system is designed to provide an efficient, user-friendly, and reliable platform for managing and conducting quizzes with automated evaluation.

The primary focus of this project is to ensure accurate quiz submissions, minimize response delays, automate grading, and generate reliable results. The application will include essential CRUD (Create, Read, Update, Delete) operations for managing quiz-related data and will incorporate five additional features from the individually assigned TQM Quality Goal.

Along with software development, the project applies TQM principles and Statistical Quality Control (SQC) tools to identify defects, analyze risks, improve system performance, and support continuous improvement.

## 2. Project Objectives

- Develop a functional and user-friendly online quiz application.
- Automate quiz evaluation and result calculation.
- Minimize submission delays and ensure reliable processing.
- Maintain accurate and consistent quiz data.
- Implement CRUD operations for managing quiz records.
- Integrate five features from the assigned TQM Quality Goal.
- Identify, analyze, and reduce software defects.
- Apply TQM principles to improve overall software quality.

## 3. Key Features

- **Quiz Management:** Create, view, update, and delete quiz-related records.
- **Automated Grading:** Evaluate submitted answers and calculate scores automatically.
- **Reliable Submissions:** Validate inputs and handle submission errors appropriately.
- **Result Management:** Calculate and display quiz results accurately.
- **Data Management:** Store and retrieve quiz information using a database.
- **Quality Enhancement:** Integrate five features from the assigned Quality Goal (Q01–Q20).
- **Defect Tracking:** Record and analyze software defects for continuous improvement.

*Note: The final feature set will depend on the assigned Quality Goal and the implemented modules.*

## 5. Application of TQM Principles

The project will apply the following Total Quality Management principles:

- **Customer Focus:** Design the application around user needs and ease of use.
- **Continuous Improvement (Kaizen):** Improve the system through repeated testing, feedback, and PDCA cycles.
- **Process-Centric Approach:** Use SIPOC diagrams to map inputs, processes, outputs, and stakeholders.
- **Fact-Based Decision Making:** Use defect records and quality data to guide improvements.
- **Error Prevention (Poka-Yoke):** Apply input validation and appropriate checks to prevent common errors.

## 6. Quality Assurance and SQC Tools

The project will use the following tools to assess and improve software quality:

- **FMEA (Failure Mode and Effects Analysis):** Identify potential failures, calculate Risk Priority Numbers (RPN), and prioritize corrective actions.
- **SIPOC Diagram:** Map the overall quiz process from suppliers and inputs to outputs and customers.
- **CTQ Tree:** Identify Critical-to-Quality requirements such as submission reliability, grading accuracy, and response time.
- **Check Sheets and Defect Logs:** Record defects, their frequency, severity, and resolution status.
- **Pareto Chart:** Identify the major defect categories requiring attention.
- **Fishbone Diagram:** Analyze the root causes of software defects.
- **PDCA Cycle:** Plan, Do, Check, and Act to support continuous quality improvement.

## 7. Project Goals

The ultimate goal is to develop a reliable, maintainable, and quality-focused Online Quiz System that meets functional requirements while applying practical TQM methodologies. The project will combine software development, systematic testing, risk analysis, defect prevention, and continuous improvement to enhance the accuracy, performance, and usability of the application.
